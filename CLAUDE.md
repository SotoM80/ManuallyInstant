
# Project:
aplicación web creada con React, Vite y TypeScript que automatiza la creación de manuales de identidad visual. Las agencias de diseño pueden cargar su logotipo principal, seleccionar fuentes de Google Fonts y configurar paletas cromáticas mediante un selector interactivo que calcula automáticamente los valores RGB y HEX. Todo este contenido se organiza dinámicamente en una plantilla única, limpia y responsiva preestablecida en la plataforma. Finalmente, el sistema permite a los usuarios exportar el documento final de forma inmediata mediante un botón funcional de descarga en formato PDF.


## Tech Stack
- **Language:** TypeScript
- **Frontend Framework:** React
- **Build Tool / Bundler:** Vite
- **Test Runner:** Jest + React Testing Library + jest-environment-jsdom
