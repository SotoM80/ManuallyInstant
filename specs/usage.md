# Technical Specification: Usage (Correct and Incorrect Use)

## 1. What it does
The third section of the Brand Manual page is **Usage**, between Logo and Colors. The user shows how the brand **must** and **must not** be used, with examples: an **image** and a **description** each. It fills two new pages of the preview, **Correct use** and **Incorrect use**, between Clear space and Color palette, so the manual has **10 pages**. Each page shows its examples in a grid with a ✓ or ✕ mark, as soon as they are typed; a new image waits for **Apply** (see `brandmanual.md` and ADR 0007).

## Out of Scope
Examples generated by the app from the logo (stretched, rotated…). Editing or cropping the images. More than one page per kind, or more than 6 examples per page. A scroll area of its own for the section, like Logo's (later, if the form turns out too long). Saving anything between sessions.

## 2. Interface
### Form (section "3. Usage")
Two groups with the same fields, one after the other: **Correct use** and **Incorrect use**.
* Each group starts with **4 empty examples**. Its examples work like the versions of the Logo section (see `logoversions.md`): an accordion where only one example of the group is open (the first one at the start); a folded one shows its description and its file name.
* **Example N image**: PNG, JPG, SVG or WebP, up to 5 MB. A new image waits for **Apply**.
* **Example N description**: free text. While empty, it shows a suggestion in grey (a placeholder, never sent to the page):

  | Example | Correct use | Incorrect use |
  |---|---|---|
  | 1 | On a light background | Don't stretch the logo |
  | 2 | On a dark background | Don't rotate the logo |
  | 3 | On a brand color | Don't change its colors |
  | 4 | With enough clear space | Don't add effects or shadows |

  Examples 5 and 6 have no suggestion.
* **Add example** adds an empty example at the end of its group and opens it; it is disabled at 6.
* **Remove** removes an example; it is hidden while the group has only one.
* **Main page**: the group being worked in decides which of the two pages comes first in the preview, with the accent outline, like the areas of the Logo section (see `brandmanual.md`). A group becomes the one being worked in when the user clicks anywhere in it or reaches it with the keyboard. When Usage opens, Correct use is the first one.

### Correct use and Incorrect use pages
* **Header**: the brand name (as on the Logo pages) and the heading "Correct use" or "Incorrect use".
* **Grid** of the examples, in the order of the form. It always fits the page, whatever the number of examples, the orientation, the view or the template:

  | Examples | Portrait | Landscape |
  |---|---|---|
  | 1 | one, the full width | the same |
  | 2 | two in a row | the same |
  | 3 | two, and the third centred below | three in a row |
  | 4 | 2 × 2 | 2 × 2 |
  | 5 | three, and two centred below | the same |
  | 6 | 3 × 2 | 3 × 2 |

* **Each example**: its image; a round **mark** on the image's top corner, ✓ in green `#2E7D32` (Correct use) or ✕ in red `#C62828` (Incorrect use), on a white circle so it shows on any image or skin; and its description below, at most 2 lines, cut with "…".
* Each example is announced to screen readers as "Correct use" or "Incorrect use"; its image's text alternative is its description, or "Example N" when it has none.
* **Templates** (ADR 0004): in Templates 1 and 2 the header is on top and the grid below; in Template 3 the header is in the left column and the grid in the right one (see `templates.md`).
* The Skin paints these pages like every inner page (ADR 0011); the descriptions and the header use its Page text color. The marks keep their own colors.

### Empty fields (live preview)
* An example with no image shows the faint striped box of an empty image, with its mark.
* An example with no description shows no text under its image.
* Each page shows its placeholder, `Your correct uses` or `Your incorrect uses`, until **its own group** is touched. Touching one group never changes the other group's page.

### Apply and the PDFs
* A new image in Usage turns **Apply** on, like a new image in Cover or Logo, and reaches its page after Apply.
* Both PDFs include the two pages, in their place (see `export.md`); the button shows "Creating… n/10".
* The export's warning about empty pages lists **Usage** while either of its pages still shows its placeholder.

### In the code
* `MANUAL_SECTIONS` gets `usage` (3rd); `MANUAL_PAGES` gets `Correct use` and `Incorrect use` (6th and 7th); `SECTION_PAGES.usage` lists both.
* The form reports its waiting images to the page (`onPendingChange`), like `BrandForm` and `LogoForm`; `canApply` in `BrandManualPage` includes it.
* `emptySections` (`src/export/exportSettings.ts`) includes Usage.

## 3. Preconditions & Postconditions
* **Preconditions**: The user is on the Brand Manual page (`/brand-manual`), in the Usage section.
* **Postconditions**: Each page shows its examples, in the order of the form, with their descriptions and their last applied images.

## 4. Invariants
* Every example has a stable id (kept while it exists, never reused), so React keeps each example's state when others are removed.
* Each group always has between 1 and 6 examples.
* The two groups are independent: changing one never changes the other or its page.
* Text reaches the page at once; a new image only after Apply.
* The page keeps the order of the form.
* The grid never falls off its page, in any orientation, view or template.

## Failure Modes
No field is required. A wrong file is flagged as soon as it is chosen, with a red border; it never turns Apply on, and the page keeps the image it had:
* **Not an image of an accepted type**: `"Use a PNG, JPG, SVG or WebP image"`.
* **Bigger than 5 MB**: `"The image must be 5 MB or smaller"`.

## 5. Given-When-Then Test Criteria

### Scenario 1: Four Empty Examples
* **Given**: The user opens "3. Usage" for the first time.
* **When**: The user looks at the form.
* **Then**: Correct use and Incorrect use have 4 examples each; the descriptions show their suggestions in grey, and both pages show their placeholders.

### Scenario 2: Live Description
* **Given**: The Usage section is open.
* **When**: The user types "Don't stretch the logo" in Incorrect use, Example 1 description.
* **Then**: At once, the Incorrect use page shows 4 examples with their ✕ marks, the first one described "Don't stretch the logo"; the Correct use page still shows its placeholder.

### Scenario 3: Image After Apply
* **Given**: The Usage section is open and Apply is off.
* **When**: The user chooses `stretched.png` for Incorrect use, Example 1, then clicks Apply.
* **Then**: Apply turns on when the file is chosen; after Apply, the Incorrect use page shows the image in the first example, and Apply is off again.

### Scenario 4: Adding Examples
* **Given**: Incorrect use has 4 examples, in portrait.
* **When**: The user clicks Add example twice.
* **Then**: The page shows three examples and two centred below, then 3 × 2; Add example is disabled.

### Scenario 5: Removing Examples
* **Given**: Correct use has 2 examples.
* **When**: The user removes one.
* **Then**: The page shows a single example, the full width, and the Remove button is no longer shown.

### Scenario 6: The Main Page Follows the Group
* **Given**: The Usage section is open, with Correct use first in the preview.
* **When**: The user clicks in the Incorrect use group.
* **Then**: The Incorrect use page moves to the first place of the preview, with the accent outline, followed by Correct use.

### Scenario 7: Three Examples in Landscape
* **Given**: Correct use has 3 examples.
* **When**: The user switches the manual to landscape.
* **Then**: The Correct use page shows the three examples in a row.

### Scenario 8: Template 3
* **Given**: Incorrect use has examples.
* **When**: The user picks Template 3.
* **Then**: The page shows the brand name and "Incorrect use" in the left column, and the grid in the right one.

### Scenario 9: Empty Pages in the PDF
* **Given**: Every other section was touched; in Usage only Correct use was.
* **When**: The user clicks ↓ Print PDF.
* **Then**: The warning says "Some pages are still empty: Usage."

### Scenario 10: Wrong File
* **Given**: The Usage section is open.
* **When**: The user chooses `rules.pdf` for Correct use, Example 2.
* **Then**: The field shows "Use a PNG, JPG, SVG or WebP image" with a red border, and Apply stays off.
